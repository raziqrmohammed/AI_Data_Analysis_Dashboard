# AI Data Analysis Dashboard

An interactive dashboard built with Streamlit that helps you explore, clean, and analyze datasets without writing code.

Upload a CSV, Excel, or JSON file to view dataset summaries, create interactive charts, discover automatic insights, and identify potentially unusual records.

## Features

- Upload CSV, Excel, and JSON datasets
- View row and column counts, data types, missing values, and duplicate records
- Clean data by handling missing values and removing duplicates
- Search and filter records
- Create interactive bar, line, pie, histogram, and scatter charts
- View a correlation heatmap for numeric columns
- Generate automatic statistical insights
- Detect potentially unusual records in numeric data
- Download filtered data, cleaned data, and an analysis report

## Built With

- Python
- Streamlit
- pandas
- NumPy
- Plotly
- scikit-learn
